# Showcase

Made with Bascik: real websites built with HTML components, scoped styles, and zero framework runtime. Explore the sites and see what people are building.

## New tool. Familiar output.

Choosing a new tool for a production site is a real decision. Bascik is already in production on business websites, an online counseling practice, and a SaaS product with a server-rendered dashboard. The sites below, including this one, show it at work.

You do not have to take the compiler's output on faith. Bascik ships HTML, JavaScript, and CSS to the browser. [Turn off minification](/configuration#minify-byominifier) to inspect the generated files yourself, then use the browser's developer tools to see what is actually running.

Bascik itself is checked with [unit, integration, and end-to-end tests](/internals/testing), including real builds and live servers. For your own project, the [testing tools](/testing) and [debugging workflows](/testing/debugging) let you test behavior and step through browser code, build scripts, and server scripts. Inspect it, test it, and debug it with tools you already know.

## Submit your site

Built something with Bascik? [Submit your site on GitHub](https://github.com/bascikdev/bascik/issues/new?template=showcase.yml).

Include your public URL, a short description, how you use Bascik, and the creator credit you would like displayed. Only submit sites you own or have permission to share. Submissions are reviewed before being added.

Please use public pages or demo data for screenshots. Do not include private dashboards, personal information, or billing details.
