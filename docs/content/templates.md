# Templates

Compare starter sites for different kinds of projects. Select any preview to open the running example. Each card shows the command that creates its template. To start with the default template, run:

```sh
npm create bascik my-site
```

## Template gallery

### Default

A simple starting point with shared components, navigation, and a theme toggle.

```sh
npm create bascik my-site
```

### Blog

An editorial site with Markdown posts, topic archives, and author context.

```sh
npm create bascik my-site -- --template blog
```

### Docs

Documentation from the first page, with search, a sidebar, highlighted section links, and Markdown pages.

```sh
npm create bascik my-site -- --template docs
```

### Landing

A product landing page with feature sections, a pricing section, and frequently asked questions.

```sh
npm create bascik my-site -- --template landing
```

### Portfolio

A creator portfolio with featured work, project pages, and an about page.

```sh
npm create bascik my-site -- --template portfolio
```

### Corporate

A company site with services, team information, and contact details.

```sh
npm create bascik my-site -- --template corporate
```

### Shop

A sample storefront that opens directly to a server-rendered product catalog, with native filters, SQLite-compatible data, and a simulated cart.

```sh
npm create bascik my-site -- --template shop
```

### Reports

A reporting site with period comparisons, charts, and downloadable CSV files.

```sh
npm create bascik my-site -- --template reports
```

### Dashboard

A dashboard with summary metrics and an activity feed.

```sh
npm create bascik my-site -- --template dashboard
```

## Make a template your own

The generated project is yours to edit. Change the sample content and adjust the components to fit your site. See [the CLI guide](/cli#scaffold-a-new-project) for scaffolding options.
