# Create Bascik Templates

Compare starter sites for different kinds of projects. Select any preview to open the running example.

## Template gallery

### Default

A simple starting point with shared components, navigation, and a theme toggle. Run `npm create bascik my-site`.

### Blog

An editorial site with Markdown posts and topic archives. Run `npm create bascik my-site -- --template blog`.

### Docs

Searchable documentation with a sidebar, section links, and Markdown pages. Run `npm create bascik my-site -- --template docs`.

### Landing

A product landing page with feature sections, a pricing section, and frequently asked questions. Run `npm create bascik my-site -- --template landing`.

### Portfolio

A creator portfolio with featured work, project pages, and an about page. Run `npm create bascik my-site -- --template portfolio`.

### Corporate

A company site with services, team information, and contact details. Run `npm create bascik my-site -- --template corporate`.

### Shop

A sample storefront with a product catalog and a simulated cart. Run `npm create bascik my-site -- --template shop`.

### Reports

A reporting site with period comparisons, charts, and downloadable CSV files. Run `npm create bascik my-site -- --template reports`.

### Dashboard

A dashboard with summary metrics and an activity feed. Run `npm create bascik my-site -- --template dashboard`.

## Make a template your own

The generated project is yours to edit. Change the sample content and adjust the components to fit your site. See [the CLI guide](/cli#scaffold-a-new-project) for scaffolding options.
