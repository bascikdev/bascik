# Sponsor

Bascik is an independent, open-source web development framework built for zero-runtime HTML components and sub-millisecond builds.

Sponsorship directly supports independent, full-time maintenance, infrastructure costs, and continuous development of the compiler, language server, developer tooling, and documentation.

## Why Sponsor?

Most modern web tooling introduces heavy client runtimes, complex virtual DOM abstractions, and bloated bundle pipelines. Bascik takes the opposite approach: scoping HTML, CSS, and JavaScript at build time while delivering standard vanilla output to the browser.

Developing and maintaining high-performance tooling requires substantial dedicated time and resources:

- **Compiler & Performance:** Ongoing optimization of the parallel worker pool, AST transformations, zero-dependency server architecture, and fast dev server live-reload.
- **Ecosystem & Tooling:** Maintaining official VS Code extensions, language server protocol (LSP) implementations, and AI agent skills.
- **Documentation & Benchmarks:** Authoring in-depth documentation, runnable demos, and verified web standard compatibility guides.
- **Infrastructure & Testing:** Running comprehensive multi-environment E2E test suites across static builds, HTTP/1.1, and HTTP/2 servers.

## Sponsorship Tiers

Sponsorship runs through [GitHub Sponsors](https://github.com/sponsors/bascikdev), monthly or one-time. The tiers below are the ones on that page today; GitHub shows the full reward text for each.

- **Individual Backer ($5 / month):** Support independent open-source development and get the Sponsor badge on your GitHub profile. The tier lists your name in a `BACKERS.md` file of the main repositories, which the project adds when the first backers join.
- **Generous Backer ($25 / month):** The same badge, with your name positioned above the standard individual backers.
- **Gold Tier Backer ($500 / month):** For organizations. A large logo on the bascik.dev front page and in the core GitHub repository READMEs.
- **Platinum Tier Backer ($1,000 / month):** For organizations. Prominent logo placement on the bascik.dev homepage, the sidebar of the content pages, and the primary GitHub README files.

Logo placements start when the first organization sponsors at those tiers. Sponsorship does not buy priority support, features, or a say in the roadmap; issues are triaged the same way for everyone.
