# How-to Overview

Each how-to guide solves one task on a real Bascik site, from rendering Markdown to serving a strict Content Security Policy. Pick the task you have, follow the steps, and copy the working example.

## Build and Content

- [Markdown](/how-to/markdown): render Markdown files and front matter at build time.
- [Build Scripts with Page Context](/how-to/page-aware-scripts): generate canonical URLs, Open Graph tags, and sidebars that depend on the current page.
- [Templating](/how-to/templating): loops, conditionals, and data in vanilla HTML with build-time scripts.
- [Optimizing Images](/how-to/optimizing-images): responsive WebP, `srcset`, and layout-stable image markup.

## Interactivity and Style

- [Interactivity](/how-to/interactivity): patterns from no code at all to fetch calls and storage.
- [Theming](/how-to/theming): design tokens, light and dark themes, and a theme toggle.
- [JavaScript Libraries](/libraries): use CDN-delivered or bundled libraries alongside Bascik.
- [Third-Party Web Components](/how-to/third-party-web-components): load a custom element from npm.
- [Bundling npm Packages](/how-to/bundling-npm-packages): run any bundler in Bascik's lifecycle pipeline.

## Production

- [Asset Fingerprinting](/how-to/asset-fingerprinting): content-hash asset filenames for long-lived CDN caching.
- [Content Security Policy](/how-to/content-security-policy): serve a strict CSP with no `'unsafe-inline'`.

## Teams and Migration

- [Sharing Components](/how-to/sharing-components): copy components between projects.
- [Publishing Components](/how-to/publishing-components): distribute components as npm packages.
- [Monorepos](/how-to/monorepos): several sites with shared components in one repository.
- [Migrating with Coding Agents](/how-to/agent-migration): move an existing site to Bascik with an agent.

## Next Steps
