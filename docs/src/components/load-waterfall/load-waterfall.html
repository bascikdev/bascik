Framework SPA

  1. Fetch HTML shell
  2. Fetch JS bundle
  3. Parse and run JS
  4. Fetch API data
  5. Render content
  6. Content visible

Four steps wait on each other before anything shows.

Static page (bascik --build)

  1. Fetch complete HTML
  2. Paint
  3. Content visible

The first response is the whole page.

Server script (data-bascik-server)

  1. Request reaches the server
  2. Script reads the data
  3. Complete HTML arrives
  4. Paint
  5. Content visible

Still one request: the data is fetched next to the backend.

Stream script (data-bascik-stream)

  1. Request reaches the server
  2. Shell flushed at once
  3. Paint the shell
  4. Content visible
  5. Script reads the data
  6. Section arrives, same response
  7. Section fills in

The page paints like a static one; the slow part streams in after.
