🚀 Hello, Bascik!

Welcome to a Bascik port of the official Astro blog starter. It is a lightweight, minimally styled starting point for a personal website, blog, or portfolio, built from plain HTML components.

Pages compile to static HTML with no framework runtime. Components live in src/components/ and Markdown posts live in content/blog/.

Here are a few ideas on how to get started with the template:

  • Edit this page in src/pages/index.html
  • Edit the site header items in src/components/site-header/site-header.html
  • Add your name to the footer in src/components/site-footer/site-footer.html
  • Check out the included blog posts in content/blog/
  • Customize the blog post layout in src/components/post-layout/post-layout.html

Have fun! If you get stuck, remember to read the docs.
