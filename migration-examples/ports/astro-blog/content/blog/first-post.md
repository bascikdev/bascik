This is the first of three short entries that stand in for the lorem ipsum posts in the original
example. It is plain Markdown, rendered to HTML when the site is built, with no runtime in the browser.

A site like this is a folder of Markdown files plus a few HTML components. Adding a post means adding a
file. The blog index, the feed, and the sitemap all pick it up on the next build.

Dates in the front matter set the order on the blog index, with the newest entry first and wide.
