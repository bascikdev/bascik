# Bascik migration ports

`astro-blog/` is the Astro blog port (task 03). `eleventy-blog/` is the Eleventy base blog port
(task 04). `nextjs-blog/` is the Next.js blog-starter port (task 09). `wordpress-blog/` reproduces a WordPress 7.1.2 blog on Twenty Twenty-Five from its REST API or a WXR export (task 09; GPL reference only, original code). Each port is a standalone npm project, not a root Yarn workspace. Declare dependencies and retain required upstream MIT notices.
Do not copy unreviewed sample content or assets.

Independent distributable starters belong in the separate, future `templates/`
directory, not here. Harness fixtures are not starter projects or migration claims.
