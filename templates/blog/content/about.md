# About

Lantern Log is a sample blog built from the Bascik blog template. Replace this page with a few words about you and what you write.

This file is `content/about.md`. It is plain Markdown with no front matter, and its first heading becomes the page title. Change the site name, description, and navigation in `src/data/site.ts`.

You can [read the first post](blog/welcome.md) or [browse the archive](/blog/). Links to other pages in `content/` are written as paths to the `.md` file and checked at build time, so a renamed or deleted post cannot leave a dead link behind.
