This is the first post of the sample blog that ships with the Bascik blog template. Each post is one Markdown file in `content/blog/`. Save a file, and it appears on the home page, in the archive, on its tag pages, in the sitemap, and in the Atom feed.

## The one rule

Every post needs a `title` and a `date` in the front matter at the top of the file. The file name becomes the address, so `welcome.md` is published at `/blog/welcome/`. Use lowercase letters, digits, and single hyphens.

If something is wrong, the build stops and names the file and the field. A missing date does not quietly produce a post that sorts to the wrong place.
