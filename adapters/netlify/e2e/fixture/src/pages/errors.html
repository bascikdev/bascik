Error demo

These routes intentionally fail so you can see how the adapter treats errors before and after a response starts.

  • Server-rendered page failure (500)

    A server script fails before response headers are committed.

  • Stream failure (200)

    The shell survives because the response has already started.

  • Server script timeout (500)

    A non-resolving server script returns a generic error response.

  • API route failure (500)

    An API handler throws and the adapter hides its internal details.
