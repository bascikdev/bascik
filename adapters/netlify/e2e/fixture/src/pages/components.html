Server-rendered cards

These cards are created for each request, not baked into the static page. A server script reads the book titles from the URL and returns a component tag for each one. Bascik renders those tags into HTML on Netlify before sending the response.

What this demonstrates: Each book title is passed as a prop, “Request-time slot” is supplied through a slot, and the stock line comes from the card's own nested server script. Both cards share one scoped stylesheet. Change the book titles and render new cards →
