The Mixed-Page Ordering Rule

Demonstrating pages that combine <script data-bascik-server> and <script data-bascik-stream> in one document response.

How Mixed Pages Execute:
1. Phase 1: All data-bascik-server scripts execute first. If any fail, the request aborts with an HTTP 500 status.
2. Phase 2: HTTP headers and static HTML preceding stream tags commit and flush immediately.
3. Phase 3: Stream script outputs flush progressively across the open connection in document source order.
