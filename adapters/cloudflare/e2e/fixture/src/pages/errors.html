Error demo

These requests intentionally fail. Server errors return a safe HTTP 500 response without exposing a stack trace. A stream that fails after headers commit keeps its HTTP 200 response and the shell already sent.

Before headers commit

  • Server failure (HTTP 500)
  • Server timeout (HTTP 500)
  • API failure (HTTP 500)

After headers commit

Stream failure (HTTP 200): the navigation, shell, and footer remain usable even though the delayed work fails.
