# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standard

Be respectful and constructive. Welcome newcomers, give and accept feedback graciously,
and focus on what is best for the project. Harassment, insults, and personal attacks are
not acceptable in issues, pull requests, or any other project space.

## Enforcement

Maintainers may edit or remove comments, close issues, or block participants who break
these rules. To report a problem, use a
[private security advisory](https://github.com/bascikdev/bascik/security/advisories/new)
or contact a maintainer through the email on their GitHub profile. Reports are handled
privately.
