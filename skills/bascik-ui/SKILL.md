# Bascik UI

Read [Visual Design and Interaction](https://bascik.dev/how-to/visual-design). Use `bascik-components` for scoping and `bascik-ux` for behavior.

- Establish the main task, existing brand assets, and one or two references before styling. Write down what to borrow, such as a layout rhythm, not what to copy. Give each site a visual direction of its own.
- Start with two compatible base tones and one accent. Reserve the accent for the main action or important information. Lower the chroma of competing colors. Status and chart series can use additional colors when they convey meaning, with labels or shapes as a second cue.
- Declare global theme tokens once and consume them in scoped components. Verify contrast, links, focus rings, and elevation separately in each color scheme.
- Choose type for the subject, not a trend. Check licenses, choose a fallback, and use tabular figures for comparable numbers. Give copy room to wrap rather than hiding required titles.
- Make the most important thing visibly dominant. Group related items with spacing before adding outlines or cards. Show the real product, examples, or data, not a decorative placeholder.
- Review the built page at phone and desktop sizes in both themes. Then check keyboard focus, zoom, long content, and layout stability after fonts and images load.
